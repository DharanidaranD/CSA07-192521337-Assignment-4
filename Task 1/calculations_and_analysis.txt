TASK 1.1 - CAUSE OF EACH COMPLAINT
1. "Someone moves a desk, everyone loses the network": a coaxial bus is ONE shared cable. Disconnecting/moving a tap or
   BNC T-connector breaks the electrical continuity and removes the terminator -> reflections -> every station fails.
   Single point of failure along the whole cable.
2. "Saving a file takes a minute at month-end": all 30 PCs + the hub floor share ONE 10 Mbps collision domain, half duplex.
   Share per PC = 10/30 = 0.33 Mbps (about 0.18 Mbps after CSMA/CD collisions/back-off). The server is at the far end of the
   cable, so it gets only the same shared bandwidth.
3. "Internet stops when the router is restarted": one home router is the only path (single point of failure) and it also does
   NAT, DHCP and Wi-Fi. A restart drops the NAT table and DHCP leases, so all sessions and addresses are lost.
Unnoticed weaknesses: (a) collisions and a single huge collision domain (hub + bus), (b) no fault isolation - faults are hard to locate,
(c) coax/hub are obsolete, limited to 10 Mbps, no QoS/VLANs, (d) cabling safety: long exposed coax across desks - trip hazard,
poor grounding, no labelling/structure, (e) security: any PC can sniff everything (hub), home router with no firewall/IDS
for client financial data, no backups/UPS, (f) growth: adding a PC means tapping the bus; maximum segment length and station count.

TASK 1.2 - REDESIGN (extended star)
 Structured Cat6A to a patch panel on each floor, one 24/48-port gigabit managed switch per floor, both uplinked (fibre or
 Cat6A, 2 x 1G LAG) to a layer-3 core switch in the server room; server on a 2x1G LAG (or 10G); business-grade router +
 firewall with UPS; optionally a second ISP link; guest Wi-Fi AP on its own VLAN. See diagrams.
 Bandwidth per computer:  BEFORE 10/30 = 0.33 Mbps shared (worst case)  ->  AFTER 1000 Mbps dedicated per port.
 Server path: 30 simultaneous saves on a 1G server link = 33 Mbps each; with 2x1G = 67 Mbps; with 10G = 333 Mbps each.
 50 MB file: before ~1200 s (all busy); after 12 s (1G server, all busy) or 0.4 s (one user).

TASK 1.3 - DEFENCE (<=100 words)
 Desk moves: star gives each PC its own cable, so moving a desk affects only that port. Slow saves: switches give every PC a
 dedicated 1 Gbps full-duplex link and remove collisions; the server gets a faster LAG uplink. Router restarts: a business
 router/firewall on UPS, with optional second ISP and static addressing/DHCP on the core, stops a restart wiping client state
 and removes the single failure point. Structured cabling, VLANs and a firewall also fix growth, safety and security.

ALTERNATIVE - ALL WIRELESS (Wi-Fi 6) vs SWITCHED STAR
 One 2x2 80 MHz AP: PHY 1201 Mbps; real shared throughput 480-720 Mbps, half duplex -> 16-24 Mbps per user for 30 users
 (vs 1000 Mbps wired). Two floors need at least 2 APs, and APs still need PoE Cat6 cabling, so the "no re-cabling" saving is
 small. Wi-Fi: cheaper to install and flexible, but variable, contention-based, interference and security exposure.
 Decision: wired switched star for the PCs and server (month-end saving); Wi-Fi 6 only for guests/laptops/phones.
